# 🍊 珊瑚音乐 · Coral Music

一个**纯静态、零依赖、零构建**的在线音乐播放器，可一键部署到 [Cloudflare Pages](https://pages.cloudflare.com/)。

珊瑚橙主题，支持浅色 / 深色模式。歌曲数据默认**只存在你自己的浏览器里**；开启「☁️ 云端」后，音频与歌单会存到**你自己的 Cloudflare R2**，不经过任何第三方服务器。

---

## ✨ 功能

- **四类音源，随心切换**
  - 💾 **本地上传**：从电脑选歌，用 IndexedDB 持久化，刷新 / 重开浏览器后仍在
  - 🌐 **在线音乐（多音源）**：一处切换四个免费音源，结果标注歌词可用性，点结果即可加入曲库 / 直接播放
    - **[GD 音乐台](https://music.gdstudio.xyz)**：免 key、聚合网易云 / 酷我 / QQ / joox / bilibili 等多平台**全曲库完整播放**；弹窗设置里可切换子音源（频率限制：5 分钟 50 次）
    - **[Audius](https://audius.co)**：免 key、可完整播放；填 API Key 提升配额；支持**用账号登录**（OAuth 2.0 PKCE，只读）载入自己发布的曲目
    - **[Jamendo](https://www.jamendo.com)**：CC 授权音乐、**完整曲目**；需在官网免费注册后填 Client ID
    - **iTunes / Apple Music**：免 key、**曲库最全**；官方只提供 **30 秒试听**（结果行有标注）
  - 🎵 **内置示例曲**：5 首免版权示例音频（SoundHelix 直链），一键载入试听
  - 🔗 **远程链接**：粘贴 mp3 / m4a 等直链添加歌曲，可选填 LRC 歌词地址
- **音频可视化**：本地歌曲走 Web Audio 画真实频谱；远程 / 示例曲跨域无法读数据时自动降级为装饰动画（避免被静音）
- **播放列表管理**：点击播放、拖拽排序、删除、随机播放、单曲 / 列表循环
- **歌词（LRC）**：自动解析 LRC 并随播放进度滚动高亮；上传歌曲时若同时选中同名的 `.lrc` 文件会**自动关联**；点歌词面板任意一行可**跳转到对应时间**；也支持手动粘贴编辑、远程链接填 LRC 地址。解析器兼容一行多时间标签、`[offset:]` 整体时间偏移，自动忽略 `[ti:]`/`[ar:]` 等元数据标签；并支持**逐字卡拉OK**（增强格式内联字级时间标签，随唱逐字点亮）与**双语歌词**（同时间戳双行自动合并原词+翻译）。歌词面板「🔍 匹配」打开**歌词匹配弹窗**：自动按歌名+歌手搜索 **GD 音乐台（网易云，含翻译）与 LRCLIB** 双来源候选列表，**手动点选**任意候选一键应用；在线加入的歌曲也会静默自动匹配（LRCLIB → GD 音乐台多级回退）
- **深色模式**：珊瑚橙主题，偏好记忆在 localStorage
- **进度续播**：记住每首歌的播放进度，下次打开自动续播
- **真实封面**：自动解析音频内嵌的 ID3 封面图
- **移动端拖拽**：手机上长按列表左侧手柄即可排序歌单
- **多歌单与收藏**：曲库共享，可建多个歌单（全部 / 收藏 / 自定义），歌曲只存一份，歌单存引用
- **独立播放队列**：右栏「队列」与歌单解耦，可追加、插队到下一首、拖拽重排、移除
- **搜索过滤**：左栏搜索框按歌名 / 歌手实时过滤当前歌单
- **均衡器 EQ**：三段均衡（低 / 中 / 高 ±12dB），偏好记忆；本地、云端与代理播放的歌曲都生效
- **倍速播放**：0.5x–2x 自由调速，切换歌曲自动沿用
- **睡眠定时**：15 / 30 / 60 分钟，或当前歌曲播完后自动停止播放
- **播放淡入淡出**：切歌与开头平滑渐入，避免爆音
- **桌面浮动歌词**：独立迷你歌词条，可拖动、可随时开关
- **歌词偏移微调**：拖动滑块整体校准歌词时间（±5 秒），补偿手写 LRC 快慢
- **云端曲库（Cloudflare R2）**：把本地上传的音频存到 R2，换设备输入同一口令即可播放；云端曲目可在线播放、加入曲库、删除
- **跨设备同步**：歌单 / 远程曲目 / 歌词 / 设置 / 播放统计与进度，一键「存到云端」与「从云端恢复」
- **在线音源代理**：由云端代理在线音频，绕开跨域限制 —— **在线歌也能出真实频谱、也能吃 EQ**
- **系统媒体控制**：锁屏 / 通知栏 / 蓝牙耳机线控直接显示封面与歌名，支持播放暂停、上下曲、±10 秒快进快退、进度条定位
- **播放历史与统计**：自动记录每首歌的播放次数与最近播放时间；歌单栏内置「最近」「最常播」两个虚拟歌单；顶栏「📊 统计」查看曲库总数、总时长、来源分布与播放排行 Top 10（可一键清空）
- **PWA 离线 / 可安装**：缓存应用壳，断网也能打开；可「添加到主屏幕」当独立 App 使用
- **歌单备份与恢复**：一键导出歌单 / 远程歌曲 / 歌词 / 设置为 JSON 文件，换设备或分享时再导入还原
- **快捷键**：`空格` 播放/暂停，`←` `→` 上一首/下一首

## 💻 本地运行

无需任何依赖与构建，用任意静态服务器打开即可（直接双击 `index.html` 也能跑，但用本地服务器能避免个别浏览器对 `file://` 的限制）：

```bash
# Python
cd online-music
python -m http.server 8080
# 浏览器打开 http://localhost:8080

# 或 Node
npx serve online-music
```

## 🚀 部署到 Cloudflare Pages

### 方式一：Cloudflare 控制台（推荐）

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → **Create** → **Pages**
2. 连接 Git 仓库 `li-luoqiang/online-music`
3. 构建配置：
   - **Framework preset**：`None`
   - **Build command**：`node scripts/check.js`（部署前跑语法 + 测试双闸门，失败则阻断部署；纯静态无构建步骤）
   - **Build output directory**：`.`
4. 保存并部署，稍等片刻即可得到 `*.pages.dev` 地址

### 配置云端（R2）——只需做一次

云端能力依赖 Pages 项目里的一个 R2 绑定，**没有它时页面会明确提示「云端未就绪」，其余功能照常可用**。

1. **创建 R2 存储桶**：Dashboard → **R2** → **Create bucket**，命名为 `music-audio`（名字随你，但要与下一处的绑定一致）
2. **绑定到 Pages 项目**：Pages 项目 → **Settings** → **Functions** → **R2 bucket bindings** → 添加：
   - **Variable name**：`MUSIC_BUCKET`（代码里用的就是这个变量名，必须一致）
   - **R2 bucket**：`music-audio`
3. **重新部署一次**（绑定变更需要新的部署才会生效）
4. **验证**：浏览器打开 `https://<你的域名>/api/ping`，看到 `{"ok":true,"hasBucket":true,"bucketOk":true,...}` 就说明通了
   - 带上口令头还能看到空间标识与云端曲目数：`curl -H "X-Coral-Key: 你的口令" https://<你的域名>/api/ping`

> `wrangler.toml` 里也声明了同一个绑定，是为了让本地 `wrangler pages dev .` 能拿到 `MUSIC_BUCKET`（见下方「本地联调云端」）。

### 方式二：Wrangler CLI

```bash
npm install -g wrangler
cd online-music
wrangler pages deploy .
```

> 仓库已自带 `wrangler.toml`（`name = "online-music"`、`pages_build_output_dir = "."` 与 R2 绑定声明），开箱即用。

### 本地联调云端

```bash
# 起本地 Pages 运行时（含 Functions 与本地模拟 R2，不触碰线上数据）
npx wrangler pages dev . --port 8788
# 然后跑一遍云端链路端到端验证（上传 → 播放 → Range 拖动 → 同步 → 删除）
node tests/probe/cloud-e2e.mjs
```

## ⚠️ 注意事项

- **数据默认只存本地**：上传的歌曲、添加的远程链接、歌词与主题偏好默认保存在当前浏览器，换设备或清缓存会丢失。开启「☁️ 云端」后可把音频与歌单存到**你自己的 Cloudflare R2**。
- **云端口令即密钥（务必抄下来）**：服务端**不保存口令**，只保存由它派生的空间标识（SHA-256 前 20 位）。所以**忘记口令等于云端数据无法再取回**；口令也决定了空间，请用 ≥10 位且不要用弱口令（弹窗里可一键生成随机口令）。
- **云端的权限边界**：写操作（上传 / 删除 / 同步 / 列表）都要请求头里的口令；音频播放地址用 `?s=<空间标识>`（`<audio src>` 无法带自定义头）。因此**空间标识泄漏只等于「别人能读你的音频」，不影响写权限，也不泄漏口令本身**；但若把播放直链公开分享出去，请知悉这一点。
- **在线音源代理**：`/api/proxy` 只代理白名单内的音源域名（Audius / GD / Jamendo / iTunes / SoundHelix / R2），且只回传音频类型，避免这个端点变成通用开放代理。它需要有效空间标识才能使用。
- **云端有免费额度**：R2 每月 10GB 存储 + 100 万次 Class A 操作，出网流量免费；Pages Functions 免费版有每日请求数上限，个人使用远够。上传单文件上限 60MB。
- **本地静态服务器下云端不可用是正常的**：`/api/*` 由 Cloudflare Pages Functions 提供，`python -m http.server` 之类的纯静态环境没有它，云端面板会明确提示「需部署到 Cloudflare Pages」，其余功能不受影响。
- **示例曲需联网**：SoundHelix 音频为在线直链，离线环境无法播放。
- **在线音乐为多音源**：「🌐 在线音乐」可切换 **Audius**（免 key、完整曲目、支持账号登录）/ **Jamendo**（CC 音乐、完整曲目、需 Client ID）/ **iTunes**（免 key、曲库最全、**仅 30 秒试听**）。三家均为**境外服务**，需联网，网络受限时可能搜索失败或加载缓慢。入库的在线曲目**只保存流地址**，不含音频文件，因此与远程歌一样受「备份不含音频」限制。
- **音源准入原则**：只接入「免 key（或前端可安全使用的 key）+ CORS 开放 + 可直接播放」的服务。已实测并排除：Internet Archive / Deezer / Openverse / ccMixter（**不返回 CORS 头，纯前端无法调用**）。
- **Audius 凭据（重要）**：Audius 给开发者两种凭据 —— **API Key 可放前端**（官方允许；本项目用它作 OAuth 的 `client_id` 兼提升配额，只在弹窗内填写、只存本机）；**Bearer Token 是后端专用，官方明确禁止放进浏览器 / 移动端代码**，本项目不收集、不保存它。
- **连接 Audius 账号走 OAuth 2.0 PKCE**（授权码 + S256，纯前端 fetch 实现，不引官方 SDK，只申请 `read` 权限，token 只存本机）。使用前需把本站域名登记到 Audius 开发者后台的 **Redirect URI** 白名单（本项目线上为 `https://online-music.pages.dev/`）。**注意：`localhost` 不在白名单内，本地环境无法完成真实授权**，请部署后在线上域名测试。
- **在线音源都不提供歌词**：Audius / Jamendo / iTunes 的接口只返回音频与元数据（歌名 / 艺术家 / 时长 / 流派），**没有任何歌词字段**。所以歌词只能来自第三方 —— 本项目用 [LRCLIB](https://lrclib.net) 按「歌名 + 艺术家」匹配时间轴歌词；若 LRCLIB 无收录，会再用 [lyrics.ovh](https://lyrics.ovh) 取**纯文本歌词**，并按每行 4 秒估算时间轴展开（此时滚动不精确，仅保证可读）。
- **远程音频跨域**：若远程音频服务器未开启 CORS，播放正常但频谱可视化会降级为装饰动画（这是浏览器安全策略，非 bug）。
- **EQ 仅本地生效**：均衡器基于 Web Audio 链路，只对本地上传歌曲生效；远程 / 示例曲走直连播放，不受 EQ 影响。
- **备份不含本地音频文件**：导出的 JSON 记录歌单结构、远程歌曲链接与歌词，但本地上传的音频二进制存在浏览器 IndexedDB，无法跨设备携带；换设备恢复后本地歌会缺失，需重新上传（远程歌与歌单结构可正常恢复）。
- **无后端**：本项目是纯前端静态站点，不包含任何服务器端代码，天然适配 Cloudflare Pages 的静态托管。
- **开发校验（双闸门 + 交互探针）**：`node scripts/check.js` 会跑「语法校验 + 逻辑测试」（114 条用例，零第三方依赖，CI 与部署前自动执行）；涉及事件绑定 / 交互的改动，另外跑 `node tests/probe/ui-probe.js` —— 它会启动无头 Chrome、用 **CDP 真实鼠标事件**驱动页面并断言结果（需本机装 Chrome，可用 `CHROME_PATH` 指定路径）。这不是洁癖：本项目曾两次出现「静态检查全绿但功能实际失效」（SW cache-first 卡旧版 JS、重写绑定后拖拽失效）。
- **播放统计只存本机**：「最近」「最常播」与 📊 统计的数据存在浏览器 localStorage（`cm-stats`），清缓存或换设备即丢失；删除某首歌时其统计会一并清理。
- **在线歌词匹配依赖第三方服务**：「🔍 匹配」候选来自 [GD 音乐台](https://music.gdstudio.xyz)（网易云源，含翻译，频率限制 5 分钟 50 次）与 [LRCLIB](https://lrclib.net) 公共服务，需要联网；均为社区维护，匹配不到时请用「✎ 编辑」手动粘贴 LRC。GD 音乐台 API 仅供学习研究，请勿商用。
