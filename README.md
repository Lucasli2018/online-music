# 🍊 珊瑚音乐 · Coral Music

一个**纯静态、零依赖、零构建**的在线音乐播放器，可一键部署到 [Cloudflare Pages](https://pages.cloudflare.com/)。

珊瑚橙主题，支持浅色 / 深色模式。歌曲数据默认**只存在你自己的浏览器里**；登录账号后，「☁️ 云端」会把音频与歌单存到**你自己的 Cloudflare R2**，不经过任何第三方服务器。**本地播放永远不需要登录。**

## ✨ 功能

- **四类音源，随心切换**
  - 💾 **本地上传**：从电脑选歌，用 IndexedDB 持久化，刷新 / 重开浏览器后仍在
  - 🌐 **在线音乐（多音源）**：一处切换四个免费音源，结果标注歌词可用性，点结果即可加入曲库 / 直接播放
    - **[GD 音乐台](https://music.gdstudio.xyz)**：免 key、聚合网易云 / 酷我 / QQ / joox / bilibili 等多平台**全曲库完整播放**；弹窗设置里可切换子音源（频率限制：5 分钟 50 次）
    - **[Audius](https://audius.co)**：免 key、可完整播放；填 API Key 提升配额；支持**用账号登录**（OAuth 2.0 PKCE，只读）载入自己发布的曲目
    - **[Jamendo](https://www.jamendo.com)**：CC 授权音乐、**完整曲目**；需在官网免费注册后填 Client ID
    - **iTunes / Apple Music**：免 key、**曲库最全**；官方只提供 **30 秒试听**（结果行有标注）
  - 🎵 **内置示例曲**：5 首免版权示例音频（SoundHelix 直链），一键载入试听
  - 🔗 **远程链接**：粘贴 mp3 / m4a 等直链添加歌曲，可选填 LRC 歌词地址
- **音频可视化**：四种模式（频谱条 / 波形 / 环形 / 极简）点封面区右上角切换，偏好记忆；可全屏铺满；本地、云端与代理歌曲走 Web Audio 画真实频谱，跨域直链读不到数据时自动降级为装饰动画（避免被静音）
- **全屏沉浸歌词**：点歌词面板「⛶ 全屏」进入大字歌词，随唱滚动、点任意行跳转，Esc 或右上角退出
- **歌词字号与行距**：A－ / A＋ 五档调节（字号变大时行距联动收紧），偏好记忆
- **歌词导出**：点「⤓ 导出」把当前歌词存成 .lrc（无时间轴的纯文本会额外提示）
- **播放列表管理**：点击播放、拖拽排序、删除、随机播放、单曲 / 列表循环
- **歌词（LRC）**：自动解析 LRC 并随播放进度滚动高亮；上传歌曲时若同时选中同名的 `.lrc` 文件会**自动关联**；点歌词面板任意一行可**跳转到对应时间**；也支持手动粘贴编辑、远程链接填 LRC 地址。解析器兼容一行多时间标签、`[offset:]` 整体时间偏移，自动忽略 `[ti:]`/`[ar:]` 等元数据标签；并支持**逐字卡拉OK**（增强格式内联字级时间标签，随唱逐字点亮）与**双语歌词**（同时间戳双行自动合并原词+翻译）。歌词面板「🔍 匹配」打开**歌词匹配弹窗**：自动按歌名+歌手搜索 **GD 音乐台（网易云，含翻译）与 LRCLIB** 双来源候选列表，**手动点选**任意候选一键应用；在线加入的歌曲也会静默自动匹配（LRCLIB → GD 音乐台多级回退）
- **深色模式**：珊瑚橙主题，偏好记忆在 localStorage
- **进度续播**：记住每首歌的播放进度，下次打开自动续播
- **真实封面**：自动解析音频内嵌的 ID3 封面图
- **移动端拖拽**：手机上长按列表左侧手柄即可排序歌单
- **移动端迷你播放条**：小屏底部固定一条迷你播放条 —— 点信息区展开全屏播放页，**左右滑切歌、上滑展开**；顶栏按钮在小屏改为横向滚动，不再堆成一大块
- **键盘快捷键**：空格播放/暂停、`←` `→` 切歌、`↑` `↓` 音量、`M` 静音、`F` 收藏、`L` 歌词面板、`Shift+L` 全屏歌词、`Q` 队列、`/` 搜索、`S` 随机、`R` 循环、`T` 深浅色、`?` 快捷键一览（顶栏 ⌨ 也能打开）
- **多歌单与收藏**：曲库共享，可建多个歌单（全部 / 收藏 / 自定义），歌曲只存一份，歌单存引用；点激活歌单标签上的 ✎ 可就地改名
- **批量多选**：左栏「☑ 多选」后勾选任意多首，一次加入歌单 / 加入队列 / 移出曲库
- **曲库排序**：默认顺序 / 添加时间 / 歌名 / 歌手 / 时长 / 播放次数 / 最近播放，偏好记忆
- **重复歌曲检测**：按「歌名 + 歌手」规范化指纹分组（自动忽略 `(Live)`、`【无损】`、扩展名等版本噪声），逐组确认保留项后一键清理其余
- **独立播放队列**：右栏「队列」与歌单解耦，可追加、插队到下一首、拖拽重排、移除
- **搜索过滤**：左栏搜索框按歌名 / 歌手实时过滤当前歌单
- **均衡器**：十段均衡（31Hz–16kHz ±12dB）+ 六种预设（平坦 / 流行 / 摇滚 / 古典 / 人声 / 低音增强），偏好记忆；本地、云端与代理播放的歌曲都生效（旧版三段设置会自动映射到十段）
- **倍速播放**：0.5x–2x 自由调速，切换歌曲自动沿用；可切换「变速不变调」保持音高
- **交叉淡入淡出**：自动切歌时新旧曲交叠渐变（0–8 秒可调）；手动切歌仍即时切换
- **响度均衡**：按播放中的 RMS 自动补偿歌曲间音量差异（0.5–2 倍，秒级时间常数，不会「呼吸」）
- **AB 段循环**：进度条下方设 A / B 两点，反复精听某一段（换歌自动清除）
- **睡眠定时**：15 / 30 / 60 分钟，或当前歌曲播完后自动停止播放
- **播放淡入淡出**：切歌与开头平滑渐入，避免爆音
- **桌面浮动歌词**：独立迷你歌词条，可拖动、可随时开关
- **歌词偏移微调**：拖动滑块整体校准歌词时间（±5 秒），补偿手写 LRC 快慢
- **云端曲库（Cloudflare R2）**：注册账号后把本地上传的音频存到 R2，换设备登录同一账号即可播放；云端曲目可在线播放、加入曲库、删除
- **账号密码登录**：用户名 + 密码注册登录（服务端只存 PBKDF2-SHA256 派生值，不存明文）；**本地播放完全免登录**，只有上传云端 / 云曲库 / 歌单同步需要；旧版「同步口令」空间的数据可一键接管过来
- **跨设备同步**：歌单 / 远程曲目 / 歌词 / 设置 / 播放统计与进度，一键「存到云端」与「从云端恢复」
- **在线音源代理**：由云端代理在线音频，绕开跨域限制 —— **在线歌也能出真实频谱、也能吃 EQ**
- **系统媒体控制**：锁屏 / 通知栏 / 蓝牙耳机线控直接显示封面与歌名，支持播放暂停、上下曲、±10 秒快进快退、进度条定位
- **播放历史与统计**：自动记录每首歌的播放次数与最近播放时间；歌单栏内置「最近」「最常播」两个虚拟歌单；顶栏「📊 统计」查看曲库总数、总时长、来源分布与播放排行 Top 10（可一键清空）
- **PWA 离线 / 可安装**：缓存应用壳，断网也能打开；可「添加到主屏幕」当独立 App 使用
- **歌单备份与恢复**：一键导出歌单 / 远程歌曲 / 歌词 / 设置为 JSON 文件，换设备或分享时再导入还原
- **快捷键**：`空格` 播放/暂停，`←` `→` 上一首/下一首

## 💻 本地运行

无需任何依赖与构建，用任意静态服务器打开即可（直接双击 `index.html` 也能跑，但用本地服务器能避免个别浏览器对 `file://` 的限制）：

```bash
# Python
cd online-music
python -m http.server 8080
# 浏览器打开 http://localhost:8080

# 或 Node
npx serve online-music
```

## 🚀 部署到 Cloudflare Pages

### 方式一：Cloudflare 控制台（推荐）

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → **Create** → **Pages**
2. 连接 Git 仓库 `li-luoqiang/online-music`
3. 构建配置：
   - **Framework preset**：`None`
   - **Build command**：`node scripts/check.js`（部署前跑语法 + 测试双闸门，失败则阻断部署；纯静态无构建步骤）
   - **Build output directory**：`.`
4. 保存并部署，稍等片刻即可得到 `*.pages.dev` 地址

### 配置云端（R2 + D1）——只需做一次

云端能力依赖 Pages 项目里的两个绑定，**缺任意一个时页面都会明确提示「云端未就绪」，其余功能照常可用**。

1. **创建 R2 存储桶**：Dashboard → **R2** → **Create bucket**，命名为 `music-audio`（名字随你，但要与下一处的绑定一致）
2. **绑定 R2 到 Pages 项目**：Pages 项目 → **Settings** → **Functions** → **R2 bucket bindings** → 添加：
   - **Variable name**：`MUSIC_BUCKET`（代码里用的就是这个变量名，必须一致）
   - **R2 bucket**：`music-audio`
3. **绑定 D1 到 Pages 项目**：Pages 项目 → **Settings** → **Functions** → **D1 database bindings** → 添加：
   - **Variable name**：`DB`
   - **D1 database**：`online-music-db`（已创建，UUID `adf62ad1-0c09-4c7f-bcbc-3452e1f7fea0`）
4. **建表**（只需一次，且必须在首次部署前做）。两种方式等价，哪个方便用哪个：
   ```bash
   # 方式 A：走 wrangler（需要先完成 wrangler 登录）
   npx wrangler d1 migrations apply online-music-db --remote

   # 方式 B：走 REST API（无人值守，只需要一个具备 D1 Edit 权限的令牌）
   CLOUDFLARE_API_TOKEN=xxx node scripts/init-d1.mjs
   #   --create 可在库不存在时自动创建；TOKEN_FILE=/path/to/token 可指定令牌文件
   ```
   两者都会建出 `users` / `sessions` / `login_attempts` 三张表与 5 个索引。**不建表的后果是所有云端接口都返回 503「账号库不可用」**。
   脚本是幂等的（全是 `CREATE ... IF NOT EXISTS`），可重复执行；执行完会打印表名、索引与行数用于自检。
5. **可选：设置 `AUTH_ITER`**（PBKDF2 迭代数，默认 100000）。若线上登录返回 500 / `1102 CPU time exceeded`，
   说明迭代数超出了当前计划的 CPU 预算 —— 在 Pages 项目 → **Settings** → **Environment variables** 里加
   `AUTH_ITER = 20000`（或 10000）后重新部署。用 `node scripts/probe-auth-cost.mjs` 可以先在本机测出各迭代数的耗时量级。
6. **重新部署一次**（绑定变更需要新的部署才会生效）
7. **验证**：浏览器打开 `https://<你的域名>/api/ping`，看到
   `{"ok":true,"hasBucket":true,"bucketOk":true,"hasDb":true,"dbOk":true,"accounts":0,...}` 就说明两个绑定都通了
   - 登录后带上令牌还能看到账号与云端曲目数：
     ```bash
     curl -H "Authorization: Bearer <登录接口返回的 token>" https://<你的域名>/api/ping
     ```

> `wrangler.toml` 里也声明了同一组绑定，是为了让本地 `wrangler pages dev .` 能拿到 `MUSIC_BUCKET` 与 `DB`（见下方「本地联调云端」）。

### 方式二：Wrangler CLI

```bash
npm install -g wrangler
cd online-music
wrangler pages deploy .
```

> 仓库已自带 `wrangler.toml`（`name = "online-music"`、`pages_build_output_dir = "."` 与 R2 / D1 绑定声明），开箱即用。

### 本地联调云端

```bash
# 1) 先把 migrations 应用到本地模拟 D1（只需一次；不建表则账号接口会 503）
npx wrangler d1 migrations apply online-music-db --local --persist-to .wrangler-dev-state

# 2) 起本地 Pages 运行时（Functions + 本地模拟 R2 / D1，不触碰线上数据）
npx wrangler pages dev . --port 8788 --persist-to .wrangler-dev-state

# 3) 跑一遍云端链路端到端验证
#    注册 → 登录 → 上传 → 播放 → Range 拖动 → 同步 → 接管旧口令空间 → 登出 → 删除
node tests/probe/cloud-e2e.mjs
```

> 探针脚本会自己完成第 1、2 步（含本地 D1 建表与运行时拉起），直接跑 `node tests/probe/cloud-e2e.mjs` 即可。
> 它会优先使用本机已安装的 wrangler（`WRANGLER_BIN` 可覆盖路径），找不到才回退 `npx` —— npx 在受限环境里
> 可能因缓存清理失败而启动不了，这是刻意的容错。
> 收尾记得清理可能残留的运行时进程：`taskkill /F /IM workerd.exe`。

## 📝 使用说明

| 操作 | 方式 |
| --- | --- |
| 添加本地歌曲 | 点右上角「＋ 上传音乐」选择音频文件 |
| 载入示例曲 | 点「🎵 示例曲」 |
| 添加远程歌曲 | 点「🔗 添加链接」，填直链（可附 LRC 歌词地址） |
| 在线音乐 | 点「🌐 在线音乐」，先选音源（GD 音乐台 / Audius / Jamendo / iTunes 试听），输入关键词搜索；点结果行 = 加入并播放，点「＋ 加入」= 只入库；每条结果标注歌词可用性（iTunes 标注「30秒试听」） |
| 切换音源 | 弹窗顶部音源标签点选即可，选择会记住；⚙ 设置里可切 GD 子音源（netease/kuwo/tencent 等）与 Audius API Key / 账号 |
| 配置 Jamendo | 切到 Jamendo 源 → 填 Client ID（在 jamendo.com 免费注册，可安全放前端）→ 回车保存 |
| 配置 Audius API Key | 在「🌐 在线音乐」弹窗内展开「⚙ Audius API Key」填写（可选，提升速率配额，同时作为 OAuth 的 client_id）。**只填 API Key —— Bearer Token 是后端专用凭据，不要填进网页** |
| 连接 Audius 账号 | 填好 API Key 后点「连接账号」→ 跳转 Audius 授权（OAuth 2.0 PKCE，只读）；授权后显示账号名，可点「我的曲目」载入自己发布的曲目，「退出」断开 |
| 上传带歌词 | 点「＋ 上传音乐」时，把音频和**同名 `.lrc`** 一起选中即可自动关联歌词 |
| 编辑歌词 | 选中一首歌后，点歌词面板「✎ 编辑」粘贴 LRC 文本 |
| 点歌词跳转 | 在歌词面板点任意一句，跳转到该句对应的播放时间 |
| 排序歌单 | 「队列」面板里拖动手柄 `⠿` 重排（队列即播放顺序） |
| 新建歌单 | 点左栏歌单栏右侧 `＋`，输入名称；点歌单标签切换，✕ 删除 |
| 重命名歌单 | 切到该歌单，点标签上的 `✎`，就地改名（回车确认 / Esc 取消） |
| 批量操作 | 点左栏「☑ 多选」进入多选态，勾选多首后统一「加入歌单 / 加入队列 / 删除」 |
| 排序曲库 | 左栏「排序」下拉选择方式（默认顺序 / 添加时间 / 歌名 / 歌手 / 时长 / 播放次数 / 最近播放） |
| 清理重复歌曲 | 点左栏「🧹 去重」扫描重复项，逐组选定要保留的那条，再点「删除各组未保留的条目」 |
| 收藏歌曲 | 点歌曲行的 ♡（变 ♥）；在「收藏」歌单查看 |
| 加入歌单 / 队列 | 点歌曲行 ⋮ 菜单：加入队列、下一首播放、加入自定义歌单 |
| 搜索 | 左栏搜索框输入歌名 / 歌手，实时过滤当前歌单 |
| 均衡器 | 点右上角 🎚 EQ，拖动低/中/高滑块（本地 / 云端 / 代理播放的歌曲都生效） |
| 备份歌单 | 点右上角 ⤓ 备份，下载 JSON（含歌单 / 远程歌曲 / 歌词 / 设置） |
| 恢复歌单 | 点 ⤒ 恢复，选择备份 JSON 还原 |
| 安装到桌面 | 浏览器菜单「安装」/「添加到主屏幕」（PWA，断网也能打开） |
| 使用云端 | 顶栏「☁️ 云端」→ 输入**用户名 + 密码**登录（或切到「注册新账号」）。登录后云端内容区才出现；换设备登录同一账号即进入同一份云端空间 |
| 注册账号 | 云端弹窗 → 「注册新账号」→ 填用户名（3–24 位小写字母 / 数字 / `_` / `-`）与密码（≥8 位），昵称选填；注册成功即自动登录 |
| 上传歌曲到云端 | 云端弹窗「⤴ 本地歌曲上传到云端」——把本机上传输的音频存进 R2，之后任何设备都能播 |
| 播放云端歌曲 | 云端列表里点 ▶ 直接播放，或点 ＋ 加入曲库后在左栏播放；🗑 从云端删除 |
| 同步歌单与设置 | 「⤒ 歌单与设置存到云端」保存快照；另一台设备登录同一账号后点「⤓ 从云端恢复」 |
| 接管旧版口令数据 | 云端弹窗（登录后）展开「有旧版『同步口令』空间的数据？」→ 输入当年的同步口令 → 点「接管数据」。**只复制不删除**，旧空间原样保留 |
| 退出登录 | 云端弹窗账号条右侧「退出登录」；只清除本机令牌与账号信息，本地曲库与云端数据都不受影响 |
| 系统媒体控制 | 手机锁屏 / 通知栏 / 蓝牙耳机线控直接控制播放与切歌，无需打开页面 |
| 查看播放统计 | 点顶栏「📊 统计」查看曲库总数、总时长、来源分布与播放排行 Top 10；右上 🗑 可清空统计 |
| 浏览最近 / 最常播 | 左栏歌单栏的「最近」「最常播」标签，按播放记录自动生成（不占歌单表） |
| 切换深浅色 | 点右上角 🌙 / ☀️，或按 `T` |
| 查快捷键 | 点顶栏 ⌨，或按 `?`；随手可用的有 `空格` 播放暂停、`←→` 切歌、`↑↓` 音量、`M` 静音、`F` 收藏、`/` 搜歌 |
| 手机上操作 | 底部迷你播放条：点信息区展开全屏播放页，**左右滑切歌、上滑展开**，右侧三个按钮控制播放 |
| 倍速播放 | 点顶栏「⏩ 倍速」选 0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x |
| 调音效 | 点顶栏「🎛 音效」：十段均衡与预设、交叉淡入淡出 0–8 秒、响度均衡、变速不变调；「恢复默认」一键复位 |
| AB 段循环 | 播放进度条下方点「A」「B」标记区间起点与终点，自动开始在该区间循环；点「✕」清除（换歌会自动清除） |
| 睡眠定时 | 点顶栏「⏲ 定时」选 15 / 30 / 60 分钟或「本曲播完停止」 |
| 桌面浮动歌词 | 点顶栏「🖥 桌面词」开关迷你歌词条（可拖动位置） |
| 歌词偏移校准 | 在歌词面板拖动「偏移」滑块（±5 秒）对齐歌词 |
| 全屏歌词 | 点歌词面板「⛶ 全屏」进入沉浸模式，点任意行跳转，Esc 退出；「A－ / A＋」调字号 |
| 导出歌词 | 点歌词面板「⤓ 导出」保存为 .lrc 文件 |
| 切换可视化 | 点封面区右上角 📊 / 〰 / ◎ / • 循环切换四种模式，旁边 ⛶ 可全屏 |
| 在线匹配歌词 | 选中一首歌后，点歌词面板「🔍 匹配」，弹窗自动搜索候选（GD 音乐台 / LRCLIB），点选任意候选一键应用；也可改关键词重新搜索 |

## ⚠️ 注意事项

- **数据默认只存本地**：上传的歌曲、添加的远程链接、歌词与主题偏好默认保存在当前浏览器，换设备或清缓存会丢失。开启「☁️ 云端」后可把音频与歌单存到**你自己的 Cloudflare R2**。
- **云端要登录，本地播放不用**：注册账号密码后即可使用云端曲库与歌单同步。**密码是加盐 PBKDF2-SHA256 派生后存储的，服务端拿不到明文**；本机只保存一枚可随时作废的登录令牌。忘记密码无法找回（可重新注册），但云端数据不会因为退出登录而丢失。
- **云端空间是随机标识，不是密码派生**：每个账号注册时随机分配一个 20 位十六进制空间标识，音频存在 `audio/<标识>/` 下。这个标识与密码无关，无法由它反推账号。
- **云端的权限边界**：写操作（上传 / 删除 / 同步 / 列表）一律要求 `Authorization: Bearer <令牌>`；只有音频播放地址用 `?s=<空间标识>`（因为 `<audio src>` 无法携带自定义请求头）。因此**空间标识泄漏只等于「别人能读你的音频」，不影响写权限**；若把播放直链公开分享出去，请知悉这一点。
- **登录有防爆破限流**：同一用户名 15 分钟内连续失败 8 次后会被暂时拒绝（返回 429）；账号不存在与密码错误返回同一句提示，避免被用来枚举已注册的用户名。
- **登录耗时与 CPU 预算**：密码校验用的是 PBKDF2-SHA256，迭代数由 `AUTH_ITER` 控制（默认 100000）。Cloudflare Workers **免费计划**单次请求 CPU 上限只有 10ms，100000 次迭代可能超限并让登录返回 500 / `1102`。遇到这种情况把 `AUTH_ITER` 降到 20000 或 10000 即可（老账号会在下次登录成功时自动升级到新迭代数）；付费计划保持默认。
- **v1「同步口令」的旧数据可以接管**：老版本的云端空间由口令派生，无法反推账号归属。注册/登录后在云端弹窗里展开「有旧版『同步口令』空间的数据？」，输入当年的同步口令即可把旧空间里的音频与歌单备份**复制**到当前账号名下。接管**只复制、不删除**源数据 —— 因为那个口令无法证明归属，一个能验证不了归属的接口不该具备破坏性副作用。
- **在线音源代理**：`/api/proxy` 只代理白名单内的音源域名（Audius / GD / Jamendo / iTunes / SoundHelix / R2），且只回传音频类型，避免这个端点变成通用开放代理。它还要求空间标识**真实对应一个已注册账号**，否则拼一个合法格式的随机标识就能白用代理。
- **云端有免费额度**：R2 每月 10GB 存储 + 100 万次 Class A 操作，出网流量免费；Pages Functions 免费版有每日请求数上限，个人使用远够。上传单文件上限 60MB。D1 免费版每天 500 万次读 / 10 万次写，账号体系这点量完全用不完。
- **本地静态服务器下云端不可用是正常的**：`/api/*` 由 Cloudflare Pages Functions 提供，`python -m http.server` 之类的纯静态环境没有它，云端面板会明确提示「需部署到 Cloudflare Pages」，其余功能不受影响。
- **示例曲需联网**：SoundHelix 音频为在线直链，离线环境无法播放。
- **在线音乐为多音源**：「🌐 在线音乐」可切换 **Audius**（免 key、完整曲目、支持账号登录）/ **Jamendo**（CC 音乐、完整曲目、需 Client ID）/ **iTunes**（免 key、曲库最全、**仅 30 秒试听**）。三家均为**境外服务**，需联网，网络受限时可能搜索失败或加载缓慢。入库的在线曲目**只保存流地址**，不含音频文件，因此与远程歌一样受「备份不含音频」限制。
- **音源准入原则**：只接入「免 key（或前端可安全使用的 key）+ CORS 开放 + 可直接播放」的服务。已实测并排除：Internet Archive / Deezer / Openverse / ccMixter（**不返回 CORS 头，纯前端无法调用**）。
- **Audius 凭据（重要）**：Audius 给开发者两种凭据 —— **API Key 可放前端**（官方允许；本项目用它作 OAuth 的 `client_id` 兼提升配额，只在弹窗内填写、只存本机）；**Bearer Token 是后端专用，官方明确禁止放进浏览器 / 移动端代码**，本项目不收集、不保存它。
- **连接 Audius 账号走 OAuth 2.0 PKCE**（授权码 + S256，纯前端 fetch 实现，不引官方 SDK，只申请 `read` 权限，token 只存本机）。使用前需把本站域名登记到 Audius 开发者后台的 **Redirect URI** 白名单（本项目线上为 `https://online-music.pages.dev/`）。**注意：`localhost` 不在白名单内，本地环境无法完成真实授权**，请部署后在线上域名测试。
- **在线音源都不提供歌词**：Audius / Jamendo / iTunes 的接口只返回音频与元数据（歌名 / 艺术家 / 时长 / 流派），**没有任何歌词字段**。所以歌词只能来自第三方 —— 本项目用 [LRCLIB](https://lrclib.net) 按「歌名 + 艺术家」匹配时间轴歌词；若 LRCLIB 无收录，会再用 [lyrics.ovh](https://lyrics.ovh) 取**纯文本歌词**，并按每行 4 秒估算时间轴展开（此时滚动不精确，仅保证可读）。
- **远程音频跨域**：若远程音频服务器未开启 CORS，播放正常但频谱可视化会降级为装饰动画（这是浏览器安全策略，非 bug）。
- **EQ 仅本地生效**：均衡器基于 Web Audio 链路，只对本地上传歌曲生效；远程 / 示例曲走直连播放，不受 EQ 影响。
- **备份不含本地音频文件**：导出的 JSON 记录歌单结构、远程歌曲链接与歌词，但本地上传的音频二进制存在浏览器 IndexedDB，无法跨设备携带；换设备恢复后本地歌会缺失，需重新上传（远程歌与歌单结构可正常恢复）。
- **无后端**：本项目是纯前端静态站点，不包含任何服务器端代码，天然适配 Cloudflare Pages 的静态托管。
- **开发校验（双闸门 + 交互探针）**：`node scripts/check.js` 会跑「语法校验 + 逻辑测试」（324 条用例，零第三方依赖，CI 与部署前自动执行）；涉及事件绑定 / 交互的改动，另外跑 `node tests/probe/ui-probe.js` —— 它会启动无头 Chrome、用 **CDP 真实鼠标与键盘事件**驱动页面并断言结果（需本机装 Chrome，可用 `CHROME_PATH` 指定路径）。这不是洁癖：本项目曾两次出现「静态检查全绿但功能实际失效」（SW cache-first 卡旧版 JS、重写绑定后拖拽失效）。
- **播放统计只存本机**：「最近」「最常播」与 📊 统计的数据存在浏览器 localStorage（`cm-stats`），清缓存或换设备即丢失；删除某首歌时其统计会一并清理。
- **在线歌词匹配依赖第三方服务**：「🔍 匹配」候选来自 [GD 音乐台](https://music.gdstudio.xyz)（网易云源，含翻译，频率限制 5 分钟 50 次）与 [LRCLIB](https://lrclib.net) 公共服务，需要联网；均为社区维护，匹配不到时请用「✎ 编辑」手动粘贴 LRC。GD 音乐台 API 仅供学习研究，请勿商用。
